# System Document Template

이 문서는 System 문서 작성 템플릿이다.

새로운 System 문서를 생성할 때 이 템플릿을 사용한다.

생성된 System 문서는 `02_Systems` 영역에 저장한다.

---

# 시스템 개요

## 시스템명

System Name

---

## 목적

이 System이 존재하는 목적을 작성한다.

이 System이 담당해야 하는 책임을 작성한다.

---

# 시스템 책임

이 System이 담당하는 책임을 작성한다.

이 System이 반드시 수행해야 하는 역할을 작성한다.

다른 System의 책임은 작성하지 않는다.

---

# 시작 조건

이 System의 동작이 시작되는 조건을 작성한다.

시작 조건은 입력, 이벤트 또는 상태 변화가 될 수 있다.

---

# 종료 조건

이 System의 동작이 종료되는 조건을 작성한다.

정상 종료와 강제 종료 조건이 있는 경우 모두 작성한다.

---

# 관리 대상

이 System이 직접 관리하는 데이터 또는 상태를 작성한다.

직접 관리하지 않는 데이터는 작성하지 않는다.

관리 대상이 없는 경우 "없음"을 작성한다.

---

# 입력

이 System가 처리하는 입력을 작성한다.

입력의 출처를 함께 작성한다.

입력이 없는 경우 "없음"을 작성한다.

---

# 출력

이 System이 생성하거나 전달하는 결과를 작성한다.

출력의 대상을 함께 작성한다.

출력이 없는 경우 "없음"을 작성한다.

---

# 시스템 경계

이 System이 담당하는 범위를 작성한다.

이 System이 담당하지 않는 범위를 작성한다.

다른 System과 책임이 겹치지 않도록 작성한다.

---

# 관련 System

현재 System과 직접 연결되는 System을 작성한다.

관련 System이 없는 경우 "없음"을 작성한다.

---

# 제약 사항

이 System이 항상 만족해야 하는 제약 사항을 작성한다.

호출 순서가 있는 경우 작성한다.

실행 조건이 있는 경우 작성한다.

성능 제약이 있는 경우 작성한다.

제약 사항이 없는 경우 "없음"을 작성한다.

---

# 문서 작성 원칙

현재 System의 정의만 작성한다.

System의 책임만 작성한다.

Feature 규칙를 작성하지 않는다.

구현 방법을 작성하지 않는다.

작업 기록을 작성하지 않는다.

변경 이력을 작성하지 않는다.

추측을 작성하지 않는다.

동일한 내용을 여러 섹션에 중복 작성하지 않는다.

System 하나당 문서 하나를 사용한다.
