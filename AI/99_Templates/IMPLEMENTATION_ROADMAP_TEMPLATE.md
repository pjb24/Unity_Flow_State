# Implementation Roadmap Template

이 문서는 `IMPLEMENTATION_ROADMAP.md` 작성 템플릿이다.

프로젝트의 구현 계획을 관리할 때 이 템플릿을 사용한다.

프로젝트에 맞게 내용을 작성한 후 `04_Implementation_Roadmap/IMPLEMENTATION_ROADMAP_<로드맵 번호>.md`로 저장한다.

이 템플릿은 문서 구조만 정의한다.

이 템플릿은 프로젝트 내용을 저장하지 않는다.

프로젝트에 적용되지 않는 섹션은 "없음"으로 작성한다.

---

# 목적

프로젝트의 구현 순서를 정의한다.

프로젝트의 개발 단계를 정의한다.

현재 개발 진행 상태를 관리한다.

다음 구현 대상을 명확하게 관리한다.

작업 기록은 작성하지 않는다.

## 목표

이 Roadmap이 대상으로 하는 개발 목표를 작성한다.

예를 들어 아래와 같은 목표를 작성한다.

```text
1차 프로토타입

얼리 액세스

정식 출시

콘텐츠 확장
```

# 개발 단계

프로젝트를 단계별로 구분하여 작성한다.

각 단계는 독립적인 목표를 가져야 한다.

각 단계는 완료 여부를 확인할 수 있어야 한다.

예를 들어 아래와 같은 형식을 사용한다.

```text
Phase 1

목표

구현 대상

완료 조건

상태
```

필요한 만큼 단계를 추가한다.

# 완료 기준

# 관련 문서

# 작성 완료 기준

현재 계획만 작성한다.

현재 진행 상태만 작성한다.

구현 방법을 작성하지 않는다.

System의 책임을 작성하지 않는다.

Feature의 규칙을 작성하지 않는다.

작업 기록를 작성하지 않는다.

변경 이력을 작성하지 않는다.

추측을 작성하지 않는다.

동일한 내용을 여러 섹션에 중복 작성하지 않는다.

프로젝트에 적용되지 않는 섹션은 "없음"으로 작성한다.
