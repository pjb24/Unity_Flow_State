# Feature Document Template

이 문서는 Feature 문서 작성 템플릿이다.

새로운 Feature 문서를 생성할 때 이 템플릿을 사용한다.

생성된 Feature 문서는 `03_Features` 영역에 저장한다.

---

# 기능 개요

## 기능명

Feature Name

---

## 목적

이 Feature가 존재하는 목적을 작성한다.

이 Feature가 사용자에게 제공하는 기능을 작성한다.

---

# 기능 규칙

이 Feature가 반드시 따라야 하는 규칙을 작성한다.

기능 수행 중 항상 만족해야 하는 규칙을 작성한다.

기능 수행 순서가 있는 경우 함께 작성한다.

---

# 시작 조건

이 Feature가 시작되는 조건을 작성한다.

사용자 입력, 게임 상태 또는 이벤트 등 Feature 시작의 기준을 작성한다.

---

# 종료 조건

이 Feature가 종료되는 조건을 작성한다.

정상 종료와 강제 종료 조건이 있는 경우 모두 작성한다.

---

# 수행 결과

Feature가 종료된 후 보장되어야 하는 결과를 작성한다.

Feature 수행으로 변경되는 상태를 작성한다.

---

# 예외 사항

Feature가 수행되지 않아야 하는 조건을 작성한다.

Feature 수행 중 예외 처리 규칙이 있는 경우 작성한다.

우선순위가 있는 규칙은 명확하게 작성한다.

예외 사항이 없는 경우 "없음"을 작성한다.

---

# 관련 System

현재 Feature를 수행하는 System을 작성한다.

관련 System이 여러 개인 경우 모두 작성한다.

관련 System이 없는 경우 "없음"을 작성한다.

---

# 제약 사항

이 Feature가 항상 만족해야 하는 제약 사항을 작성한다.

호출 순서가 있는 경우 작성한다.

실행 조건이 있는 경우 작성한다.

성능 제약이 있는 경우 작성한다.

제약 사항이 없는 경우 "없음"을 작성한다.

---

# 검증 항목

Feature가 정상적으로 동작하는지 확인해야 하는 항목을 작성한다.

Feature 수정 시 반드시 확인해야 하는 항목을 작성한다.

회귀 검증이 필요한 항목을 작성한다.

검증 항목이 없는 경우 "없음"을 작성한다.

---

# 문서 작성 원칙

현재 Feature의 정의만 작성한다.

Feature의 규칙만 작성한다.

System의 책임을 작성하지 않는다.

구현 방법을 작성하지 않는다.

작업 기록을 작성하지 않는다.

변경 이력을 작성하지 않는다.

추측을 작성하지 않는다.

동일한 내용을 여러 섹션에 중복 작성하지 않는다.

Feature 하나당 문서 하나를 사용한다.
