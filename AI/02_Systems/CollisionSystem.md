# 시스템 개요

## 시스템명

CollisionSystem

---

## 목적

Player와 충돌 대상의 충돌 상태를 관리한다.

충돌 결과 정보를 생성하여 필요한 System에 제공한다.

---

# 시스템 책임

- Player의 충돌 상태를 판정한다.
- 원본 충돌 정보를 생성한다.
- 원본 충돌 정보를 기반으로 파생 정보를 생성한다.
- 충돌 결과 정보를 관리한다.
- 충돌 결과 정보를 필요한 System에 제공한다.

---

# 시작 조건

- GameSystem이 System 초기화를 요청한다.
- Player GameObject가 생성된다.
- Player Rigidbody와 Collider가 준비된다.

---

# 종료 조건

## 정상 종료

- 플레이가 종료된다.
- GameSystem이 게임 종료 절차를 시작한다.

## 강제 종료

- Unity가 게임을 종료한다.

---

# 관리 대상

## 원본 충돌 정보

- 현재 충돌 여부
- 현재 충돌 대상
- 현재 접촉 지점
- 현재 접촉 표면의 법선 벡터

---

## 파생 충돌 정보

- 현재 접촉 표면의 기울기

---

## 충돌 결과 정보

- 현재 충돌 결과 정보

---

# 입력

| 입력 | 출처 |
|------|------|
| Player 위치 | PlayerControllerSystem |
| Player 물리 상태 | PlayerControllerSystem |
| Collider 충돌 정보 | Unity Physics |

---

# 출력

| 출력 | 대상 |
|------|------|
| 충돌 결과 정보 | PlayerMovementSystem |

---

# 시스템 경계

## 담당 범위

- 충돌 판정
- 원본 충돌 정보 생성
- 파생 충돌 정보 생성
- 충돌 결과 정보 관리
- 충돌 결과 정보 제공

---

## 담당하지 않는 범위

- Player 이동
- Player Rigidbody 제어
- 입력 처리
- 이동 계산
- 점프 규칙 정의
- 관성 착지 규칙 정의
- 경사면 이동 규칙 정의
- 충돌 결과를 이용한 행동 결정
- Stage 진행
- UI 처리
- 게임 전체 흐름 관리

---

# 관련 System

- GameSystem
- PlayerControllerSystem
- PlayerMovementSystem

---

# 제약 사항

- Player를 직접 이동시키지 않는다.
- Rigidbody를 직접 제어하지 않는다.
- 이동 결과를 계산하지 않는다.
- Feature 규칙을 정의하지 않는다.
- 충돌 결과를 기반으로 행동을 결정하지 않는다.
- Unity Physics가 제공하는 충돌 정보를 기준으로 원본 충돌 정보를 생성한다.
- 파생 충돌 정보는 원본 충돌 정보만을 이용하여 생성한다.
- 충돌 결과 정보만 관리하고 제공한다.

---

# 문서 작성 원칙

현재 System의 정의만 작성한다.

System의 책임만 작성한다.

Feature 규칙을 작성하지 않는다.

구현 방법을 작성하지 않는다.

작업 기록을 작성하지 않는다.

변경 이력을 작성하지 않는다.

추측을 작성하지 않는다.

동일한 내용을 여러 섹션에 중복 작성하지 않는다.

System 하나당 문서 하나를 사용한다.
