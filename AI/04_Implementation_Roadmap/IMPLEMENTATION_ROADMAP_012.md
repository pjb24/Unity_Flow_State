# 목적

InfiniteMode의 캐릭터 외형과 동작 표현을 개선하고 물리·착지 판정과 시각 표현의 일치를 유지한다.

# 프로젝트 정보

## 프로젝트명

Flow State

## 목표

Roadmap 12 — 캐릭터 그래픽과 동작 표현 강화.

계획 확정일: 2026-11-11. **계획 확정·구현 미착수**이며 각 Phase의 상태는 대기다.
선행: [Roadmap 11](IMPLEMENTATION_ROADMAP_011.md) 완료 후 순차 착수한다.
공통 순서·승인/검증 경계는 [로드맵 안내](README.md)를 따른다.

## 범위 밖

캐릭터 성장/스킨 판매 기능, 새로운 이동 능력, 물리·속도·착지 판정 변경.

# 개발 단계

## Phase 1. 캐릭터 표현 범위·애셋 확정

### 목표

공통 스타일에 맞는 캐릭터 표현 범위를 확정한다.

### 구현 대상

- 모델/외형·재질·표시 크기·동작 상태/Animation 범위 결정.
- Roadmap 10의 원본 관리·복원 기준에 따른 애셋 도입 검토.
- 착지 위치·위험 요소를 읽을 수 있는 캐릭터 가독성 기준 정리.

### 완료 조건

- 새 표현의 상태/자산 범위와 도입 조건이 정해져 있다.
- Roadmap 11의 피드백을 중복 구현하지 않는 경계가 명확하다.
- 물리/점수 변경 없이 외형을 교체하는 완료 기준이 있다.

### 상태

대기 — 구현/실행 검증 미착수.

## Phase 2. 외형·Animation 적용

### 목표

플레이 상태와 어긋나지 않는 캐릭터 표현을 제공한다.

### 구현 대상

- 확정 외형과 필요한 동작/전환 표현 적용.
- Jump·공중·착지·종료·Pause·Retry 상태의 시각 연동.
- Roadmap 11의 착지/획득/실패 피드백과 조합.

### 완료 조건

- 표시 위치/크기/방향과 착지 판정의 관계가 적절하다.
- Animation이 이동/Collider/점수의 판정 주체를 대체하지 않는다.
- 상태 복귀·일시 중단/재시작에서 잘못된 포즈/효과가 남지 않는다.

### 상태

대기 — 구현/실행 검증 미착수.

## Phase 3. 가독성·통합 회귀

### 목표

기존 맵에서 조작 결과를 읽을 수 있는 후보를 확정한다.

### 구현 대상

- 상태 연동 자동 검증과 외형/동작/가독성 사용자 확인.
- 기존 Pattern·카메라·HUD·피드백과 조합 점검.
- 도입 의존성 복원과 Roadmap 13 배경 대비 기준 인계.

### 완료 조건

- 게임 규칙 회귀와 사용자 시각 확인 결과가 확보되어 있다.
- 현재 맵에서도 캐릭터/착지점/위험을 구별할 수 있다.
- Thirdparty 비추적/복원 기준을 유지한다.

### 상태

대기 — 구현/실행 검증 미착수.

# 완료 기준

InfiniteMode의 캐릭터 외형과 동작 표현을 개선하고 물리·착지 판정과 시각 표현의 일치를 유지한다.
각 Phase의 완료 근거와 관련 문서 반영·회귀 검증 결과를 확보하고 범위 밖 기능/데이터 변경을 수행하지 않는다.
계획 승인만으로 실제 구현/사용자 검증·원격 배포·공개 개시가 승인되거나 성공한 것으로 기록하지 않는다.
