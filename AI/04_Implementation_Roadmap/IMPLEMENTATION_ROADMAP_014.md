# 목적

InfiniteMode 중심 화면에 공통 시각 스타일을 적용하고 기능 상태·정보 위계·입력 접근성을 일관되게 정리한다.

# 프로젝트 정보

## 프로젝트명

Flow State

## 목표

Roadmap 14 — UI 스타일 통합과 가독성 강화.

계획 확정일: 2026-11-11. **계획 확정·구현 미착수**이며 각 Phase의 상태는 대기다.
선행: [Roadmap 13](IMPLEMENTATION_ROADMAP_013.md) 완료 후 순차 착수한다.
공통 순서·승인/검증 경계는 [로드맵 안내](README.md)를 따른다.

## 범위 밖

Stage 기능 복원, 계정/점수/제출 정책 재설계, 신규 플랫폼/언어/Gamepad 지원의 자동 추가, Steam/일반 공개 자동 승인.

# 개발 단계

## Phase 1. 스타일·적용 화면 확정

### 목표

앞선 캐릭터/맵/피드백과 조화되는 UI 적용 범위를 정한다.

### 구현 대상

- Main Menu·HUD·Pause·Result·Settings·How To Play·Leaderboard·계정/이전·Notice 화면 목록 정리.
- 글꼴·색상·패널·버튼·선택/비활성/Loading/오류 상태와 정보 위계 결정.
- 실제 지원 범위와 Thirdparty 폰트/아이콘 등 도입/복원 조건 확정.

### 완료 조건

- Stage 진입/기록 기능을 되살리지 않는 화면 목록이 확정되어 있다.
- Roadmap 11의 결과 전달 의미와 공통 스타일을 승계한다.
- 제품/글꼴/언어·화면 지원 확장은 필요시 별도 승인 대상으로 구분되어 있다.

### 상태

대기 — 구현/실행 검증 미착수.

## Phase 2. 화면별 스타일 적용

### 목표

기존 기능 의미와 입력 흐름을 보존하며 화면을 통일한다.

### 구현 대상

- 공통 요소와 각 화면의 타이포그래피/배치/상태 표현 적용.
- 기존 Keyboard/Mouse 선택·Submit/Cancel·Back·모달/포커스 복귀 유지.
- 개인 최고·이번 Run·제출 상태·온라인 순위/미기록/오류의 구별 유지.

### 완료 조건

- 색상/장식만이 아니라 정보 위계와 기능 상태를 구분할 수 있다.
- 핵심 정보/버튼이 겹치거나 화면 밖으로 숨지 않는다.
- 계정/이전·Pending·동의 흐름과 비밀값 비노출 경계를 유지한다.

### 상태

대기 — 구현/실행 검증 미착수.

## Phase 3. 통합 스타일 후보 검증

### 목표

실제 화면 가독성과 기존 기능 보존을 함께 확인한다.

### 구현 대상

- Navigation/상태 전환·참조 정적/자동 검증과 실제 화면 확인 범위 준비.
- 캐릭터/맵/피드백/HUD 전체 화면의 일관성 확인.
- 검증된 빌드/설정·도입 자산 기준과 잔여 위험 정리.

### 완료 조건

- 스타일 변경 대상의 자동 회귀와 사용자 화면/입력 검증 근거를 확보했다.
- Roadmap 11~13 결과와 화면 스타일이 충돌하지 않는다.
- 원본 비추적·의존성 복원을 유지하고 공개 여부는 별도로 결정한다.

### 상태

대기 — 구현/실행 검증 미착수.
