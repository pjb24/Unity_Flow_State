# 목적

기존 Pattern의 플레이 구조를 유지하면서 지형·배경·재질·조명과 위험/획득 요소의 시각적 구분을 개선한다.

# 프로젝트 정보

## 프로젝트명

Flow State

## 목표

Roadmap 13 — 맵 그래픽과 공간 가독성 강화.

계획 확정일: 2026-11-11. **계획 확정·구현 미착수**이며 각 Phase의 상태는 대기다.
선행: [Roadmap 12](IMPLEMENTATION_ROADMAP_012.md) 완료 후 순차 착수한다.
공통 순서·승인/검증 경계는 [로드맵 안내](README.md)를 따른다.

## 범위 밖

Pattern 선택/연결 알고리즘·난이도·위험 보상 규칙 개선, 신규 장애물/이동 능력·Collectible 점수/배치 정책 변경. 그래픽 작업을 이유로 경쟁 조건을 조용히 변경하지 않는다.

# 개발 단계

## Phase 1. 맵 표현·가독성 기준 확정

### 목표

캐릭터와 UI를 방해하지 않는 맵 스타일을 정한다.

### 구현 대상

- 공통 스타일과 캐릭터 대비에 맞는 지형/배경·재질·조명 범위 결정.
- 착지면·Gap·Wall·Collectible·장식의 구별 기준 정리.
- Thirdparty 도입/복원과 반복 Pattern 경계의 표현 범위 결정.

### 완료 조건

- 착지 가능한 면과 장식/배경을 구분할 수 있는 목표가 있다.
- 기존 Pattern geometry/연결/난이도를 변경하지 않는 범위가 명확하다.
- 새 애셋의 사용·복원 조건이 정리되어 있다.

### 상태

대기 — 구현/실행 검증 미착수.

## Phase 2. 맵 표현 적용

### 목표

기존 통과 가능성과 연결을 유지하며 시각 표현을 교체한다.

### 구현 대상

- 기존 Pattern별 지형/장식/배경·조명 표현 적용.
- Slot 재사용/Pattern 전환·Collectible 수명과 시각 요소 연동.
- 캐릭터/피드백/카메라/HUD와 명암·겹침 조정.

### 완료 조건

- 시각 교체로 Collider/Anchor/통과 가능성·점수 배치가 의도치 않게 바뀌지 않는다.
- 재사용/전환 뒤 시각 누락·중복·이전 구간 잔류가 없다.
- 위험과 착지면·Collectible이 외형으로 오인되지 않는다.

### 상태

대기 — 구현/실행 검증 미착수.

## Phase 3. 시각 통합·회귀 검증

### 목표

반복 지형에서도 조작과 결과를 읽을 수 있는 후보를 확정한다.

### 구현 대상

- 기존 Pattern/연결·생명주기 자동 회귀와 실제 시각 확인.
- 캐릭터 대비/가림·맵 경계·조명 변화/피드백 가독성 점검.
- UI 최종 스타일에 필요한 화면 대비/색상 인계.

### 완료 조건

- 기존 플레이/점수·온라인 계약과 시각 결과의 보존 근거가 있다.
- 대상 화면에서 위험·캐릭터·착지점의 식별을 확인했다.
- Thirdparty 비추적/복원 기준을 유지한다.

### 상태

대기 — 구현/실행 검증 미착수.
