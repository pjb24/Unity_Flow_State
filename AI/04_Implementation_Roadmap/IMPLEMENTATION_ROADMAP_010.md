# 개발 단계

## Phase 1. 원본·프로젝트 소유 자료 경계 확정

### 목표

제외할 파일과 유지할 도입 정보를 구분한다.

### 구현 대상

- 기존 Thirdparty/패키지·추적 상태·배포물/의존성의 목록 조사.
- 원본/파생 자료·자체 코드/설정·연결용 애셋과 .meta 관리 범위 결정.
- 제품/버전·취득 경로·사용 조건·도입 담당 및 재취득 가능성 확인.

### 완료 조건

- 단순 폴더명뿐 아니라 실제 내용/출처를 기준으로 제외 범위가 정해져 있다.
- Unity Package 의존성 선언과 lock 정보 등 복원용 정보의 관리 범위가 정해져 있다.
- 외부 원본 복사본/파생물의 관리 판단과 비밀값/유료 원본을 포함하지 않는 기록 범위가 명확하다.

### 상태

완료(2026-11-19) — [Phase 1 Task Step 10](../90_Tasks/Prototype_10/20261118_02_Phase1ManualSteps.md)에 세 완료 조건의 근거와 실제 적용/복원 의무를 연결했다. 현재 도입 애셋은 없고 불명확한 자료는 보존하며, 관리 기록/형식·Node 도구와 정책 포함 Unit Test 55개 근거를 마련했다. 최신 inventory exit 1의 기존 finding은 보존 범위 비차단·실제 적용/복원 전 검증 대상으로 구분했으며 참조 정상/권리·독립 복원 PASS가 아니다. Phase 2도 완료(2026-11-20)했다. Phase 3 Step 1~10과 Roadmap 10도 완료(2026-11-25)했다. 현재 기술 기준선의 범위/한계는 Phase 3 최종 인계를 따른다.

## Phase 2. 형상 관리 제외와 도입·복원 절차

### 목표

원본 유입을 막고 동일 의존성을 다시 준비할 수 있게 한다.

### 구현 대상

- 추적 중/미추적 Thirdparty 구분과 제외 규칙/유입 검사 정비.
- 프로젝트 설정과 외부 원본의 분리 및 필요한 재적용 정보 관리.
- 버전·경로·GUID/Import 설정·참조 안정성을 포함한 도입/복원 절차 준비.

### 완료 조건

- 관리 대상 외부 원본이 현재 Git 추적/신규 staged 후보에 포함되지 않음을 검사할 수 있다.
- 애셋 누락/버전 불일치를 식별하고 적법하게 재도입할 수 있다.
- 외부 원본을 직접 수정하지 않는 확장 경계와 필요한 설정 재현 방법이 정리되어 있다.

### 상태

완료(2026-11-20) — [Phase 2 Task](../90_Tasks/Prototype_10/20261119_05_Phase2ManualSteps.md)에 기준선·등록/정책·도입/보존·Git 유입/복원·lifecycle·정적/Unit Test·조건부 사용자 검증과 최종 인계를 Step 1~10으로 정리했다. Step 7의 lifecycle 절차/판정에 이어 Step 8에서 부작용 감사·전체 Node Test 261개와 현재 저장소/보존본·HEAD/index 불변 검증을 완료했다. Step 9에서 생산 자산/설정·C#·Scene/Prefab·선언/lock 불변과 실제 요청 0개에 따라 현재 사용자 실행 불필요·조건부 후속 실행을 연결했다. Step 10에서 현재 CLI/입력·세 조건을 대조해 Phase 2만 완료하고 [Phase 3 인계](../90_Tasks/Prototype_10/20261120_02_Phase3Handoff.md)와 새 기준선을 마련했다. 실제 원본 추적 해제/삭제·lifecycle 적용·선언/lock 변경·설치·권리/독립 Unity 복원 성공은 아니다.

## Phase 3. 독립 복원 검증과 후속 도입 인계

### 목표

### 구현 대상

- 기존 작업본을 보존하는 별도 환경에서 checkout/의존성 도입 검증 계획.
- Prefab/Material/Animation/Scene 참조와 Import 설정 보존 확인.
- Roadmap 11~14에서 도입할 사운드/그래픽/UI 애셋에 적용할 점검 기준 인계.

- 원본 비추적과 프로젝트 소유 파일 보존을 함께 검증했다.
- 복원 제약/수동 도입 단계와 검사 결과를 기록했다.

### 상태

완료(2026-11-25) — [Phase 3 Task Step 10](../90_Tasks/Prototype_10/20261120_04_Phase3ManualSteps.md)에서 실제 UPM/TMP·npm/NuGet·필수 참조/사용자 Unity 검증과 비추적/자체 자료 보존·제약 기록의 세 조건을 충족했다. [최종 인계](../90_Tasks/Prototype_10/20261125_37_Phase3RestoreAndAdoptionHandoff.md)와 [최종 검증](../90_Tasks/Prototype_10/20261125_38_Phase3Step10FinalVerification.json)을 따른다. 현재 기술 기준선의 복원 완료이며 raw audit exit 1/기존 31회 GUID 진단, 제품별 권리·모든 Player/variant·원격/container 미검증 한계는 유지한다. 추가 수동 실행은 없다.
