# Rules Documents

이 문서는 Rules 영역의 진입 문서이다.

Rules 영역에 존재하는 문서와 각 문서의 책임을 정의한다.

---

# 목적

Rules 영역은 프로젝트 규칙을 관리한다.

Rules 영역은 코드 규칙을 관리한다.

Rules 영역은 구현 규칙을 관리한다.

Rules 영역은 조사 규칙을 관리한다.

Rules 영역은 검증 규칙을 관리한다.

Rules 영역은 프로젝트 정보를 관리하지 않는다.

Rules 영역은 시스템 책임을 관리하지 않는다.

Rules 영역은 기능 규칙을 관리하지 않는다.

Rules 영역은 작업 기록을 관리하지 않는다.

---

# 문서 목록

Rules 영역에는 아래 문서가 존재해야 한다.

```text
AI_RULE.md

CODING_STYLE.md

EVENT_RULE.md

LOGGING_RULE.md

INVESTIGATION_RULE.md

IMPLEMENTATION_RULE.md

VERIFICATION_RULE.md
```

---

# AI_RULE.md

AI가 작업할 때 따라야 하는 최상위 규칙을 관리한다.

AI가 판단할 때 우선해야 하는 기준을 관리한다.

AI가 작업을 수행하는 원칙을 관리한다.

---

# 문서 작성 책임

동일한 규칙을 여러 문서에 중복 작성하지 않는다.

각 문서는 자신의 책임 범위만 관리한다.

---

# 문서 작성 원칙

Rules 영역 문서는 규칙만 관리한다.

프로젝트 정보는 Project 영역에서 관리한다.

시스템 책임은 Systems 영역에서 관리한다.

기능 규칙은 Features 영역에서 관리한다.

작업 기록은 Tasks 영역에서 관리한다.

문서 작성 형식은 Templates 영역에서 관리한다.

문서에 정의된 내용을 우선한다.
