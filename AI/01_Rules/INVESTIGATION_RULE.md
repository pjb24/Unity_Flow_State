# 목적

프로젝트에서 조사 작업을 수행할 때 적용하는 규칙을 정의한다.

조사 결과의 신뢰성을 유지하기 위한 기준을 정의한다.

조사 과정에서 근거를 확보하는 기준을 정의한다.

---

# 적용 범위

이 문서의 규칙은 프로젝트의 모든 조사 작업에 적용한다.

예외가 필요한 경우 별도의 Rule 문서에서 정의한다.

---

# 조사 원칙

조사를 시작하기 전에 관련 문서를 먼저 확인한다.

확인된 사실만 조사 결과로 사용한다.

추측과 확인된 사실을 명확하게 구분한다.

조사 결과는 재현 가능한 근거를 기반으로 작성한다.

조사 대상의 책임 범위를 벗어나지 않는다.

문서와 구현 내용이 다른 경우 둘 모두 확인한 후 차이를 명확하게 기록한다.

---

# 조사 대상 확인 기준

조사 목적을 먼저 확인한다.

조사 대상이 Project, Rules, System, Feature 중 어디에 속하는지 확인한다.

조사 대상과 직접 관련된 문서를 우선 확인한다.

관련 코드가 있는 경우 문서와 함께 확인한다.

조사 범위는 작업 목적에 필요한 최소 범위로 제한한다.

---

# 근거 수집 기준

확인 가능한 문서와 코드를 근거로 사용한다.

문서와 구현이 일치하는 경우 둘 모두 근거로 사용할 수 있다.

문서와 구현이 일치하지 않는 경우 차이를 명확하게 기록한다.

근거가 부족한 경우 결론을 내리지 않는다.

확인되지 않은 내용은 근거로 사용하지 않는다.

---

# 원인 분석 기준

현상과 원인을 구분한다.

원인은 확인된 근거를 기반으로 판단한다.

추측을 원인으로 기록하지 않는다.

원인이 확인되지 않은 경우 원인을 추정하지 않는다.

여러 가능성이 있는 경우 각각을 사실처럼 기록하지 않는다.

---

# 조사 결과 기록 기준

조사 과정과 조사 결과를 구분하여 기록한다.

확인한 사실만 조사 결과에 기록한다.

조사 결과에는 근거를 함께 기록한다.

조사 결과가 기존 문서와 충돌하는 경우 어느 쪽이 최신 정보인지 확인한 후 기록한다.

확인되지 않은 내용은 기록하지 않는다.

추가 조사가 필요한 경우 그 이유를 명확하게 기록한다.

---

# 조사 종료 기준

조사 목적에 필요한 근거가 확보된 경우 조사를 종료한다.

원인이 확인된 경우 조사를 종료할 수 있다.

근거가 부족한 경우 추가 조사가 필요하다고 기록한다.

조사 과정에서 문서 오류를 확인한 경우 구현과 별도로 문서 수정이 필요한지 함께 판단한다.

조사 목적과 직접 관련 없는 추가 문제를 발견한 경우 조사 범위를 임의로 확장하지 않는다.

추가 문제는 별도의 조사 또는 작업 대상으로 분리한다.

추측으로 빈 부분을 채우지 않는다.

---

# 금지 사항

확인되지 않은 내용을 사실로 작성하지 않는다.

추측을 근거로 결론을 내리지 않는다.

근거 없이 원인을 단정하지 않는다.

조사 결과를 생략하지 않는다.

문서를 확인하지 않고 코드만 보고 결론을 내리지 않는다.

코드를 확인하지 않고 문서만 보고 구현 상태를 단정하지 않는다.

조사 범위를 임의로 확대하여 작업 목적과 무관한 결론을 내리지 않는다.
