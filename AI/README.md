# AI Documentation Entry Point

이 문서는 AI 문서 체계의 최상위 문서이다.

새로운 작업을 시작하기 전에 가장 먼저 이 문서를 확인한다.

---

# 목적

이 문서는 AI 문서 체계의 구조를 정의한다.

이 문서는 각 영역의 책임을 정의한다.

이 문서는 문서 확인 순서를 정의한다.

이 문서는 문서 생성 위치를 정의한다.

세부 내용은 각 영역의 문서에서 관리한다.

---

# 표준 문서 구조

AI 문서는 아래 구조를 기준으로 관리한다.

```text
AI
├─ README.md

├─ 00_Project
├─ 01_Rules
├─ 02_Systems
├─ 03_Features

├─ 90_Tasks

└─ 99_Templates
```

프로젝트에 따라 하위 문서는 달라질 수 있다.

각 영역의 역할은 변경하지 않는다.

---

# 영역 정의

## 00_Project

프로젝트 정보를 관리한다.

프로젝트 목표를 관리한다.

프로젝트 구조를 관리한다.

프로젝트 설계를 관리한다.

---

## 01_Rules

프로젝트 규칙을 관리한다.

코드 규칙을 관리한다.

구현 규칙을 관리한다.

조사 규칙을 관리한다.

검증 규칙을 관리한다.

---

## 02_Systems

시스템 책임을 관리한다.

시스템 경계를 관리한다.

시스템 간 관계를 관리한다.

---

## 03_Features

기능 규칙을 관리한다.

기능 조건을 관리한다.

기능 결과를 관리한다.

---

## 90_Tasks

실제 작업 기록을 관리한다.

작업 수행 결과를 관리한다.

작업 이력을 관리한다.

---

## 99_Templates

문서 작성 형식을 관리한다.

설계 문서 템플릿을 관리한다.

작업 기록 템플릿을 관리한다.

---

# 문서 확인 순서

새로운 작업을 시작하는 경우 아래 순서로 문서를 확인한다.

```text
1. AI/README.md

2. 00_Project/README.md

3. 01_Rules/README.md
```

프로젝트 정보와 프로젝트 규칙을 이해한 후 작업을 시작한다.

---

# 추가 문서 확인

작업 대상이 특정 System인 경우

```text
02_Systems/README.md
```

를 확인한다.

---

작업 대상이 특정 Feature인 경우

```text
03_Features/README.md
```

를 확인한다.

---

작업 기록이 필요한 경우

```text
99_Templates/README.md
```

를 확인한다.

---

# 문서 생성 위치

새로운 System 문서는 아래 위치에 생성한다.

```text
02_Systems
```

---

새로운 Feature 문서는 아래 위치에 생성한다.

```text
03_Features
```

---

작업 기록 문서는 아래 위치에 생성한다.

```text
90_Tasks
```

---

문서 작성 템플릿은 아래 위치에서 관리한다.

```text
99_Templates
```

---

# Systems 와 Features

Systems 문서는 아래 질문에 답한다.

```text
누가 담당하는가?
```

---

Features 문서는 아래 질문에 답한다.

```text
어떻게 동작해야 하는가?
```

---

동일한 내용을 Systems 와 Features 양쪽에 작성하지 않는다.

---

# Tasks 와 Templates

Tasks 영역은 실제 작업 기록을 관리한다.

작업 기록은 Tasks 영역에 저장한다.

Templates 영역은 문서 작성 형식을 관리한다.

문서 작성 형식은 Templates 영역에 저장한다.

동일한 내용을 여러 영역에 중복 저장하지 않는다.
