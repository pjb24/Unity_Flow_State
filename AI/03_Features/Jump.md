# 기능 개요

## 기능명

Jump

---

## 목적

플레이어가 지면을 벗어나 새로운 이동 경로를 선택할 수 있도록 한다.

관성 착지와 연결되는 이동의 시작 동작을 제공한다.

---

# 기능 규칙

- 점프는 플레이어의 점프 입력으로 시작한다.
- 점프 가능한 상태에서만 점프를 시작할 수 있다.
- 점프는 중력의 크기와 관계없이 항상 동일한 최고 높이에 도달해야 한다.
- 지면을 벗어난 직후의 짧은 허용 시간(코요테 타임) 동안에는 점프를 시작할 수 있다.
- 점프가 시작되면 플레이어는 공중 상태가 된다.
- 공중 상태에서는 새로운 점프를 시작할 수 없다.
- 점프가 종료되기 직전에 Momentum Landing Window가 활성화된다.
- 모든 점프는 하나의 착지로 종료된다.
- 착지는 Momentum Landing 또는 Normal Landing 중 하나로 판정된다.

---

# 시작 조건

다음 조건을 모두 만족하는 경우 점프를 시작한다.

- 플레이어가 점프 입력을 수행한다.
- 플레이어가 점프 가능한 상태이다.

점프 가능한 상태는 아래 중 하나를 만족한다.

- 지면에 있다.
- 코요테 타임이 아직 종료되지 않았다.

---

# 종료 조건

## 정상 종료

- 플레이어가 지면에 착지한다.

## 강제 종료

- Stage가 종료된다.
- 게임이 종료된다.

---

# 수행 결과

- 플레이어가 공중 상태가 된다.
- 플레이어가 착지 가능한 상태가 된다.
- 점프는 항상 동일한 최고 높이까지 수행된다.
- 착지 직전에 Momentum Landing Window가 활성화된다.
- 이후 Momentum Landing 또는 Normal Landing Feature로 연결된다.

---

# 예외 사항

- 점프 가능한 상태가 아니면 점프를 시작하지 않는다.
- 코요테 타임이 종료된 이후에는 공중에서 점프를 시작하지 않는다.
- 게임 진행이 중단된 상태에서는 점프를 시작하지 않는다.

---

# 관련 System

- PlayerInputSystem
- PlayerMovementSystem
- CollisionSystem

---

# 제약 사항

- 하나의 점프는 하나의 착지로 종료되어야 한다.
- 하나의 점프 도중 새로운 점프를 시작할 수 없다.
- 점프는 항상 동일한 최고 높이를 유지해야 한다.
- Momentum Landing Window는 점프마다 한 번만 활성화된다.
- 점프는 항상 Momentum Landing 또는 Normal Landing으로 연결되어야 한다.

---

# 검증 항목

- 지면에서 점프가 정상적으로 시작되는지 확인한다.
- 코요테 타임 동안 점프가 가능한지 확인한다.
- 코요테 타임 종료 후에는 점프가 시작되지 않는지 확인한다.
- 중력 설정을 변경하여도 점프 최고 높이가 동일한지 확인한다.
- 공중 상태에서는 새로운 점프가 시작되지 않는지 확인한다.
- 점프 종료 직전에 Momentum Landing Window가 활성화되는지 확인한다.
- 착지 후 Momentum Landing 또는 Normal Landing으로 정상 연결되는지 확인한다.
- 착지 후 다시 점프할 수 있는지 확인한다.

---

# 문서 작성 원칙

현재 Feature의 정의만 작성한다.

Feature의 규칙만 작성한다.

System의 책임을 작성하지 않는다.

구현 방법을 작성하지 않는다.

작업 기록을 작성하지 않는다.

변경 이력을 작성하지 않는다.

추측을 작성하지 않는다.

동일한 내용을 여러 섹션에 중복 작성하지 않는다.

Feature 하나당 문서 하나를 사용한다.
