# 기능 개요

## 기능명

MomentumLanding

---

## 목적

플레이어가 착지 직전의 타이밍 입력을 연속으로 성공하여 InfiniteMode의 거리 Score 배율을 높일 수 있도록 한다.

게임의 핵심 이동 재미와 숙련도 요소를 제공한다.

---

# 기능 규칙

- Momentum Landing Window는 관성 착지를 입력할 수 있는 판정 시간이다.
- Momentum Landing Window는 착지 직전에만 활성화된다.
- Momentum Landing Window는 플레이어가 공중 상태이고 CollisionSystem이 착지 후보 지면까지의 유효한 거리를 제공할 때 활성화 여부를 판정한다.
- 착지 후보 지면의 탐지와 실제 지면 접촉은 서로 다른 상태로 취급한다.
- 플레이어는 Momentum Landing Window 동안 관성 착지 입력을 수행할 수 있다.
- Momentum Landing Window 동안 입력이 수행되면 관성 착지를 수행한다.
- 관성 착지가 수행되면 플레이어의 이동 흐름은 유지된다.
- 관성 착지는 플레이어의 이동 속도를 증가시키지 않는다.
- 관성 착지 성공 전후에는 동일한 수평 이동 속도 규칙을 사용한다.
- Momentum Landing Window가 종료될 때까지 입력이 수행되지 않으면 일반 착지를 수행한다.
- 하나의 점프에서는 하나의 관성 착지만 수행할 수 있다.
- 실제 지면 접촉으로 완료된 Momentum Landing 한 번을 연속 성공 한 번으로 판정한다.
- 일반 Stage에서는 Momentum Landing 성공이 Score 배율을 변경하지 않는다.

---

# InfiniteMode Score 배율 규칙

| 연속 성공 | 현재 배율 | 유지 시간 |
|---:|---:|---:|
| 0회 | `1.00x` | 제한 없음 |
| 1회 | `1.25x` | `10.0`초 |
| 2회 | `1.50x` | `9.5`초 |
| 3회 | `1.75x` | `9.0`초 |
| 4회 | `2.00x` | `8.5`초 |
| 5회 | `2.25x` | `8.0`초 |
| 6회 | `2.50x` | `7.5`초 |
| 7회 | `2.75x` | `7.0`초 |
| 8회 이상 | `3.00x` | `6.5`초 |

- 새 InfiniteMode Run은 연속 성공 `0회`, 배율 `1.00x`에서 시작한다.
- Momentum Landing이 완료된 시점에 연속 성공을 한 번 증가시키고 새 배율을 적용한다.
- 상승한 배율은 성공 착지 이후 발생한 이동 거리 증가분부터 적용한다.
- Momentum Landing 성공마다 새 배율의 전체 유지 시간으로 남은 시간을 갱신한다.
- 최대 배율에서 추가 성공하면 배율은 유지하고 남은 시간을 `6.5`초로 갱신한다.
- 일반 착지와 Wall 접촉만으로는 연속 성공, 배율 또는 남은 시간을 초기화하지 않는다.
- 마지막 성공 후 현재 배율의 유지 시간이 지나도록 추가 성공이 없으면 연속 성공을 `0회`, 배율을 `1.00x`로 초기화한다.
- 배율 만료와 Momentum Landing 성공이 같은 물리 갱신에서 발생하면 성공을 먼저 처리한다.
- 배율 유지 시간은 InfiniteMode Playing 상태의 게임 진행 시간만 사용한다.
- Pause에서는 연속 성공, 현재 배율과 남은 시간을 보존하고 시간을 차감하지 않는다.
- Resume에서는 보존한 상태와 남은 시간부터 계속한다.
- Result에서는 최종 상태를 고정하고 배율 진행과 시간 차감을 수행하지 않는다.
- 낙하로 Run이 종료되어도 이미 획득한 Score를 제거하지 않는다.
- Retry와 새 Run은 연속 성공, 현재 배율과 남은 시간을 초기화한다.

# 시작 조건

다음 조건을 모두 만족하는 경우 관성 착지를 시작한다.

- 플레이어가 공중 상태이다.
- Momentum Landing Window가 활성화되었다.
- 플레이어가 Momentum Landing Window 동안 관성 착지 입력을 수행하였다.
- 플레이어가 지면에 착지하였다.

---

# 종료 조건

## 정상 종료

- 관성 착지 처리가 완료된다.
- 플레이어가 지면 이동 상태가 된다.

## 강제 종료

- Momentum Landing Window가 종료된다.
- Stage가 종료된다.
- 게임이 종료된다.

---

# 수행 결과

- 플레이어가 지면 이동 상태가 된다.
- 플레이어의 이동 속도는 Momentum Landing 때문에 증가하지 않는다.
- InfiniteMode에서는 연속 성공 상태와 거리 Score 배율이 갱신된다.
- 이후 일반 지면 이동을 계속 수행할 수 있다.

---

# 예외 사항

- Momentum Landing Window 외의 입력은 관성 착지로 인정하지 않는다.
- 공중 상태가 아니면 수행하지 않는다.
- 하나의 점프에서 두 번 이상 수행하지 않는다.
- 게임 진행이 중단된 상태에서는 수행하지 않는다.
- 음수, `NaN` 또는 무한대 시간 입력은 배율 유지 시간 계산에 사용하지 않는다.

---

# 관련 System

- PlayerInputSystem
- PlayerMovementSystem
- CollisionSystem

---

# 제약 사항

- Momentum Landing Window는 점프마다 한 번만 활성화된다.
- 하나의 착지에 대해 한 번만 판정한다.
- 관성 착지 실패 시 반드시 일반 착지를 수행한다.
- 관성 착지는 항상 점프 이후에만 수행한다.
- 실제 지면 접촉 전에는 관성 착지를 완료하지 않는다.
- 배율이 `1.00x`이면 유지 시간 제한을 적용하지 않는다.
- 시간 만료는 이미 확정된 Base Distance Score, Momentum Bonus 또는 Collectible Score를 감소시키지 않는다.

---

# 검증 항목

- Momentum Landing Window가 착지 직전에 활성화되는지 확인한다.
- Momentum Landing Window 동안 입력하면 관성 착지가 수행되는지 확인한다.
- Momentum Landing Window 이전의 입력은 성공하지 않는지 확인한다.
- Momentum Landing Window 종료 후의 입력은 성공하지 않는지 확인한다.
- 관성 착지 수행 전후에 동일한 수평 이동 속도 규칙을 사용하는지 확인한다.
- 입력하지 않으면 일반 착지가 수행되는지 확인한다.
- 하나의 착지에서 두 번 이상 수행되지 않는지 확인한다.
- 관성 착지 후 정상적으로 지면 이동이 가능한지 확인한다.
- Stage 종료 시 관성 착지가 종료되는지 확인한다.
- InfiniteMode의 연속 성공마다 배율 단계가 `0.25x`씩 증가하고 `3.00x`에서 고정되는지 확인한다.
- 각 배율 단계에서 정해진 유지 시간을 사용하고 성공 시 해당 단계의 전체 시간으로 갱신되는지 확인한다.
- 일반 착지와 Wall 접촉만으로 배율이 초기화되지 않는지 확인한다.
- 유지 시간 만료 시 `1.00x`로 초기화되는지 확인한다.
- Pause와 Result에서는 남은 시간이 감소하지 않고 Retry와 새 Run에서는 초기화되는지 확인한다.
- 일반 Stage의 Momentum Landing이 Score 배율을 변경하지 않는지 확인한다.

# 문서 작성 원칙

현재 Feature의 정의만 작성한다.

Feature의 규칙만 작성한다.

System의 책임을 작성하지 않는다.

구현 방법을 작성하지 않는다.

작업 기록을 작성하지 않는다.

변경 이력을 작성하지 않는다.

추측을 작성하지 않는다.

동일한 내용을 여러 섹션에 중복 작성하지 않는다.

Feature 하나당 문서 하나를 사용한다.
